# Redux

Redux Toolkit хранит состояние интерфейса, которое живёт только в браузере:
уведомления, открытые окна и т. п. Данные с сервера в Redux не кладём, они
живут в TanStack Query (см. [TanStack Query](tanstack-query.md)). Иначе
появятся два источника правды, которые придётся синхронизировать вручную.

## Как подключено

| Что                               | Где                                       |
| --------------------------------- | ----------------------------------------- |
| Создание стора (`makeStore`)      | `src/app/store/makeStore.ts`              |
| Провайдер стора (`StoreProvider`) | `src/app/providers/StoreProvider.tsx`     |
| Подключение провайдера            | `app/layout.tsx`, снаружи `QueryProvider` |

## Почему стор создаёт функция

Стор создаёт функция `makeStore`, а вызывает её `StoreProvider` через
`useState(makeStore)`, так же как `QueryProvider` создаёт `QueryClient`.

Клиентские компоненты отрисовываются не только в браузере, но и на сервере,
чтобы отдать готовый HTML. Сервер Next это одна программа на всех посетителей.
Стор, созданный в файле (`export const store = configureStore(...)`), был бы
на сервере один на всех, и состояние одного посетителя попадало бы в страницу
другого. Провайдер же появляется заново на каждое открытие страницы, поэтому
у каждого посетителя свой стор. В браузере стор один на вкладку.

## Правила

-   **Готовый стор на уровне файла не создаём.** Только через `makeStore`
    в `StoreProvider`.
-   **Стор читают и меняют только клиентские компоненты** (`'use client'`).
    Серверный компонент выполняется только на сервере, и его изменения
    браузер не увидит.
-   **В сторе только состояние интерфейса.** Данные с сервера и статусы
    запросов даёт TanStack Query.

## Как добавить слайс

1. Создать слайс через `createSlice` в сегменте `model` своего слайса FSD,
   например `src/shared/ui/success-alert/model/successAlertSlice.ts`.
2. Экспортировать редьюсер через `index.ts` слайса.
3. Добавить редьюсер в `rootReducer` в `src/app/store/makeStore.ts`.
   Ключ в `rootReducer` должен совпадать с тем, по которому селектор слайса
   читает состояние.
