# General Information (настройки профиля)

Документ описывает содержимое таба General information на странице настроек
профиля (задача BLD-65): форму с данными пользователя и фото профиля. Какие файлы
созданы, как их подключить и что пока не готово.

Макет — Figma, экран General information. Контракт с бэкендом — Swagger.

## Как подключить на страницу

Таб состоит из двух фич: форма (`edit-profile`) и фото (`change-profile-photo`).
По правилам FSD фича не может импортировать другую фичу, поэтому их соединяет
страница: передаёт фото в форму через проп `photo`.

```tsx
import { useCurrentUser } from '@/entities/session';
import { ProfilePhoto } from '@/features/change-profile-photo';
import { EditProfileForm } from '@/features/edit-profile';

const { data: user } = useCurrentUser();

// под табом General information
<main>
    {user && <EditProfileForm username={user.username} photo={<ProfilePhoto />} />}
</main>;
```

-   `username` — из `GET /api/v1/auth/me`. Остальных полей профиля в API пока нет,
    поэтому они открываются пустыми.
-   `photo` — необязательный. Без него форма работает, просто без колонки с фото.
-   Сама страница настроек с табами — отдельная задача.

## features/edit-profile — форма

### Поля

| Поле          | Правила                                              |
| ------------- | ---------------------------------------------------- |
| Username\*    | 6–30 символов: латиница, цифры, `_` и `-`            |
| First Name\*  | до 50 символов, только буквы (латиница и кириллица)  |
| Last Name\*   | то же, что First Name                                |
| Date of birth | необязательное, возраст не меньше 13 лет             |
| Country, City | необязательные, город выбирается только после страны |
| About Me      | до 200 символов                                      |

Тексты ошибок — в `model/rules.ts`. Ошибка возраста заканчивается ссылкой
Privacy Policy на `/privacy-policy`, как в макете.

Правила username такие же, как при регистрации (`RegistrationDto` в Swagger).

### Поведение

-   Ошибка поля появляется, когда пользователь уходит с поля (`mode: 'onTouched'`),
    дальше поле проверяется при каждом вводе.
-   Кнопка «Save Changes» неактивна, пока в форме есть ошибки или пустые
    обязательные поля.
-   При смене страны выбранный город сбрасывается: старый город новой стране не
    подходит.
-   Дату рождения можно напечатать цифрами (слэши ставит маска) или выбрать в
    календаре по иконке.
-   `DatePicker` и `Select` подключены через `Controller` из React Hook Form:
    это наши компоненты, а не обычные `<input>`. У них свои `value` и `onChange`,
    а значение даты — объект `Date`, а не строка.

## features/change-profile-photo — фото

### Как работает

1.  «Select Profile Photo» открывает окно «Add a Profile Photo».
2.  «Select from Computer» открывает выбор файла на компьютере.
3.  Файл проверяется (таблица ниже). Если не подходит, сверху окна появляется
    ошибка.
4.  Подходящее фото показывается под круглой маской: его можно двигать мышью,
    пальцем или стрелками и приближать до 3 раз.
5.  «Save» вырезает выбранную область, и она становится аватаркой.
6.  Красный крестик на аватарке открывает окно «Delete Photo». «Yes» удаляет
    фото, «No» закрывает окно.

| Проверка          | Текст ошибки                                                 |
| ----------------- | ------------------------------------------------------------ |
| только PNG и JPEG | Error! The format of the uploaded photo must be PNG and JPEG |
| не больше 10 MB   | Error! Photo size must be less than 10 MB!                   |

### Как устроено

-   **Обрезка.** Библиотека `react-easy-crop` показывает фото под кругом и сообщает,
    какой квадрат выбран. Сам квадрат вырезает `getCroppedImage`: рисует его на
    `<canvas>` и получает файл (`Blob`). Формат сохраняется исходный, чтобы у PNG
    не пропала прозрачность.
-   **Временные ссылки.** Чтобы показать фото до загрузки на сервер, используем
    `URL.createObjectURL`. Когда ссылка больше не нужна, освобождаем её через
    `URL.revokeObjectURL`, иначе браузер держит файл в памяти.
-   **Скрытый `<input type="file">`.** Стандартное поле выбора файла нельзя
    оформить как в макете, поэтому оно спрятано, а кнопка «Select from Computer»
    нажимает его через `ref`.

## shared/ui/date-picker — fullWidth и ввод даты

Две доработки общего `DatePicker`, обе описаны в
[README DatePicker](../src/shared/ui/date-picker/README.md):

-   **Проп `fullWidth`.** В макете поле даты растянуто на всю ширину формы. Без
    пропа компонент работает как раньше.
-   **Ввод даты с клавиатуры.** В календаре нет выбора года, и листать до года
    рождения по месяцам долго. Поэтому дату можно напечатать: пользователь вводит
    только цифры `12121989`, а маска сама ставит слэши `12/12/1989`. Когда дата
    дописана, открытый календарь переходит на её месяц. Маска — в
    `lib/maskDate.ts`, превращение текста в дату — в `lib/parseDate.ts`.
    `onChange` теперь получает и `undefined`, когда поле очистили.

## Ограничения и что дальше

-   **Сохранение профиля и фото — заглушки.** В API нет эндпоинтов для обновления
    профиля и аватарки, поэтому в коде стоят `TODO`. Фото хранится только в
    браузере и пропадает после перезагрузки страницы.
-   **Страны и города — временный список** из четырёх стран в `model/options.ts`.
    Когда в API появится справочник, список заменим на запрос через `useQuery`.
-   **Имя, фамилия, дата рождения, город и «About Me»** не приходят с сервера:
    `GET /api/v1/auth/me` возвращает только `userId`, `username` и `email`.
-   **Отличия от макета:** круг обрезки 332px вместо 316px. Поле даты рождения
    принимает ввод с клавиатуры, в макете его нет.
