# Popover

Переиспользуемый компонент всплывающего содержимого.

## Импорт

```tsx
import { Popover } from '@/shared/ui/popover';
```

## Пример

```tsx
<Popover trigger={<span>Открыть</span>} align="end">
    <div>Содержимое поповера</div>
</Popover>
```

Компонент открывается по нажатию на триггер и закрывается повторным нажатием,
кликом за его пределами или клавишей Escape. `align` определяет выравнивание
содержимого относительно триггера и принимает значения `start` и `end`.

Если триггер содержит только иконку, передайте `triggerLabel` для доступного
названия кнопки.
