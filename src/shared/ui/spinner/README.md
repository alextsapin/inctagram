# Spinner

Крутящееся кольцо, которое показывает, что что-то загружается.

## Назначение

Spinner ставят на место содержимого, которое ещё не пришло: фото поста, следующую порцию постов. Кольцо полупрозрачное белое, дуга сверху белая (`--color-light-100`). Спиннер рассчитан на тёмный фон: на светлом его почти не видно.

Компонент только рисует кольцо. Где его разместить (по центру блока, рядом с текстом), решает родитель.

Скринридер спиннер не читает (`aria-hidden`). Если пользователю нужно услышать о загрузке, родитель даёт подпись сам, например блок с `role="status"` и текстом «Loading posts…».

## Импорт

```tsx
import { Spinner } from '@/shared/ui/spinner';
```

## Свойства (Props)

| Prop   | Тип      | По умолчанию | Назначение                        |
| ------ | -------- | ------------ | --------------------------------- |
| `size` | `number` | `20`         | Ширина и высота кольца в пикселях |

## Рядом с текстом

```tsx
<div role="status">
    <Spinner />
    Loading posts…
</div>
```

## По центру блока

Блок с фото растягивается на всю карточку, а спиннер ставится поверх по центру:

```tsx
<div className={s.photo}>
    {isLoading && (
        <div className={s.loader}>
            <Spinner size={40} />
        </div>
    )}
    <Image src={url} alt="" fill />
</div>
```

```scss
.photo {
    position: relative;
}

.loader {
    position: absolute;
    inset: 0;
    display: flex;
    align-items: center;
    justify-content: center;
}
```

## Где используется

-   `PostGridItem` в сетке постов профиля: пока фото поста не загрузилось.
-   `CarouselSlide` в карусели поста: пока фото не загрузилось.
-   `InfinitePostGrid`: под сеткой, пока грузится следующая порция постов.
