# Tabs

Универсальные табы (вкладки) для интерфейса Inctagram.

## Назначение

`Tabs` — общий UI-компонент для переключения между разделами одной страницы: General information, Devices, Account Management и My payments в Profile Settings, Week и Month в Statistics.

Компонент лежит в слое `shared` архитектуры FSD, потому что это переиспользуемый элемент без привязки к конкретной фиче. Его можно импортировать из любого слоя выше: `features`, `widgets`, `pages`.

Содержимое выбранного таба передаём в `Tabs` как `children`, и компонент показывает его под табами. Какое содержимое передать, решает страница по выбранному `value`.

Клавиатура и доступность сделаны по стандарту WAI-ARIA [«Tabs with Automatic Activation»](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/examples/tabs-automatic/).

## Импорт

```tsx
import { Tabs, type TabOption } from '@/shared/ui/tabs';
```

Импортируй только через публичный API слайса (`index.ts`). Не пиши пути вида `@/shared/ui/tabs/ui/Tabs`: внутреннее устройство папки может измениться, а публичный экспорт останется стабильным.

## Свойства (Props)

| Prop         | Тип                       | По умолчанию | Назначение                                          |
| ------------ | ------------------------- | ------------ | --------------------------------------------------- |
| `options`    | `TabOption[]`             | —            | Табы (обязательный)                                 |
| `value`      | `string`                  | —            | `value` выбранного таба (обязательный)              |
| `onChange`   | `(value: string) => void` | —            | Вызывается при выборе таба (обязательный)           |
| `fullWidth`  | `boolean`                 | `false`      | Табы на всю ширину родителя, все одной ширины       |
| `aria-label` | `string`                  | —            | Название группы табов для скринридера (рекомендуем) |
| `children`   | `React.ReactNode`         | —            | Содержимое выбранного таба, показывается под табами |

Один таб:

```ts
type TabOption = {
    value: string; // что придёт в onChange
    label: string; // текст на табе
    disabled?: boolean; // таб виден, но выбрать его нельзя
};
```

Компонент управляемый (controlled): выбранный таб хранит родитель в `value` и обновляет в `onChange`.

Ширина:

-   без `fullWidth` таб шириной по тексту, но не уже 85px, как Week и Month в Statistics;
-   с `fullWidth` табы делят ширину родителя поровну, как в Profile Settings;
-   если табы не помещаются (узкий экран), они не сжимаются, а прокручиваются вбок.

## Как работает

### Мышь

-   Клик по табу выбирает его.
-   Отключённый таб не нажимается.

### Клавиатура

| Клавиша         | Что делает                                                       |
| --------------- | ---------------------------------------------------------------- |
| `Tab`           | перейти в группу табов (на выбранный таб) или выйти из неё       |
| `→`             | выбрать следующий таб, с последнего перейти на первый            |
| `←`             | выбрать предыдущий таб, с первого перейти на последний           |
| `Home`, `End`   | выбрать первый / последний таб                                   |
| `Enter`, пробел | нажать таб, как кликом. Обычно не нужно: стрелка уже выбрала таб |

-   Таб выбирается сразу, как только на него перешли стрелкой.
-   Отключённые табы стрелки пропускают.
-   По `Tab` в группу попадает только один таб: выбранный, а если он отключён, то первый доступный. Поэтому, чтобы пройти мимо табов, хватает одного нажатия `Tab`.

### Скринридер

Группа — `role="tablist"` с `aria-label`, каждый таб — `role="tab"` с `aria-selected`. Поэтому скринридер называет таб вкладкой и говорит, выбрана ли она.

Если передать `children`, компонент сам рисует под табами панель (`role="tabpanel"`) и связывает её с табами, как требует стандарт. id создаёт React через `useId()`, например:

```html
<!-- выбран второй таб, Devices -->
<button id="_R_1_-tab-1" role="tab" aria-selected="true" aria-controls="_R_1_-panel">
    Devices
</button>

<div id="_R_1_-panel" role="tabpanel" aria-labelledby="_R_1_-tab-1">...</div>
```

-   `aria-controls` у таба указывает на панель: скринридер знает, каким блоком управляет таб.
-   `aria-labelledby` у панели указывает на выбранный таб: скринридер читает панель как «Devices».
-   Панель одна на все табы, меняется только её содержимое. Поэтому `aria-controls` у всех табов указывает на одну и ту же панель, и ссылка никогда не ведёт на несуществующий блок.
-   id писать не нужно: `useId()` даёт каждому `Tabs` свой уникальный id, даже если на странице несколько групп табов.
-   Без `children` панели нет, и у табов нет `aria-controls`: ссылаться не на что.

## Практические примеры

### 1. Profile Settings: табы на всю ширину

```tsx
const settingsTabs: TabOption[] = [
    { value: 'general', label: 'General information' },
    { value: 'devices', label: 'Devices' },
    { value: 'account', label: 'Account Management' },
    { value: 'payments', label: 'My payments' },
];

const [tab, setTab] = useState('general');

<Tabs
    options={settingsTabs}
    value={tab}
    onChange={setTab}
    fullWidth
    aria-label="Profile settings"
>
    {tab === 'general' && <GeneralInformation />}
    {tab === 'devices' && <Devices />}
    {tab === 'account' && <AccountManagement />}
    {tab === 'payments' && <MyPayments />}
</Tabs>;
```

Панель встаёт сразу под табами. Отступ между ними (в макете 24px) задаёт родитель или само содержимое.

### 2. Statistics: Week и Month

Без `fullWidth` табы шириной по тексту. Где они стоят (например, справа), задаёт родитель. Отдельного раздела под табами нет (они переключают период у графика), поэтому `children` не передаём:

```tsx
const periods: TabOption[] = [
    { value: 'week', label: 'Week' },
    { value: 'month', label: 'Month' },
];

const [period, setPeriod] = useState('week');

<div className={css.period}>
    <Tabs options={periods} value={period} onChange={setPeriod} aria-label="Period" />
</div>;
```

```scss
.period {
    display: flex;
    justify-content: flex-end; /* табы справа, как в макете */
}
```

### 3. Отключённый таб

Таб виден, но выбрать его нельзя ни мышью, ни стрелками. Например, раздел ещё не готов:

```tsx
const settingsTabs: TabOption[] = [
    { value: 'general', label: 'General information' },
    { value: 'payments', label: 'My payments', disabled: true },
];
```

## Состояния

Визуальные состояния описаны в `tabs.module.scss` по макету Figma (компонент Tabs на странице Components). Отдельно прописывать их в своём SCSS не нужно.

| Состояние                 | Невыбранный таб                                                 | Выбранный таб                |
| ------------------------- | --------------------------------------------------------------- | ---------------------------- |
| Default                   | текст и полоса снизу 2px `#4C4C4C`                              | текст и полоса 2px `#397DF6` |
| Hover                     | фон `#234E99`, прозрачность 15%                                 | так же                       |
| Active (в момент нажатия) | фон `#73A5FF`, прозрачность 15%                                 | так же                       |
| Focus                     | рамка 2px `#2F68CC` внутри таба, только при работе с клавиатуры | так же                       |
| Disabled                  | текст и полоса `#333333`                                        | текст и полоса `#234E99`     |

Размеры: высота 36px, текст 16px / 24px Semi Bold, отступы слева и справа 16px, ширина таба не меньше 85px.

## Как устроен код

```text
tabs/
├── lib/
│   ├── getNextTabIndex.ts  ← какой таб выбрать по стрелкам, Home и End
│   └── types.ts            ← тип TabOption
├── ui/
│   ├── Tabs.tsx            ← разметка, клик, клавиатура и панель
│   └── tabs.module.scss    ← стили и состояния
├── index.ts
└── README.md
```

-   `lib/getNextTabIndex.ts` — функция без React: получает нажатую клавишу, табы и номер текущего таба, возвращает номер нового или `null`, если клавиша не для табов. Отключённые табы пропускает, по стрелкам ходит по кругу.
-   `ui/Tabs.tsx` — кнопки табов. `tabIndex={0}` только у одного таба, у остальных `-1`, поэтому `Tab` попадает в группу один раз. После стрелки компонент вызывает `onChange` и сам переводит фокус на новый таб. Если передан `children`, под табами рисуется панель: её id и id табов строятся из `useId()`, а `aria-labelledby` панели указывает на выбранный таб.
-   `ui/tabs.module.scss` — все состояния из макета. Рамка фокуса через `:focus-visible`, поэтому после клика мышью её нет. В режиме `fullWidth` у табов `flex: 1` и `min-width: auto`: табы одной ширины, но не уже своего текста.

## Использование в Next.js

У компонента стоит `'use client'`, потому что внутри есть обработчики событий, `useRef` и `useId`. Родитель, который хранит выбранный таб в `useState`, тоже должен быть клиентским.

## Ограничения текущего API

-   Табы не меняют адрес страницы. Если выбранный таб должен сохраняться после перезагрузки, страница сама хранит его в адресе (например, `?tab=devices`) и передаёт в `value`.
-   Только горизонтальные табы: стрелки `↑` и `↓` не обрабатываются.
-   Нет иконок и счётчиков на табах: в макете их нет.
-   Какое содержимое передать в `children`, решает страница по `value`: компонент сам содержимое не выбирает.
-   Панель всегда стоит сразу под табами. Если содержимое нужно показать в другом месте страницы, это отдельная доработка.
